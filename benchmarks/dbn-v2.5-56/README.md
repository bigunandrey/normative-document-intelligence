# DBN V.2.5-56 benchmark fixture

This benchmark targets the real DBN V.2.5-56:2014 source with Changes No. 1 and 2 used previously in Fire Protection Engine.

The repository does not redistribute the PDF by default. The benchmark runner should accept a locally supplied fixture and record:

- source filename;
- SHA-256;
- page count;
- parser versions;
- extraction timing;
- structural counts;
- table observations;
- discrepancy counts;
- recognition gate result.

Expected source properties from the established fixture:

- 105 pages;
- selectable PDF text;
- source SHA-256: `fbaa2493ed510d621e8f368ec4910e5cc30d177744f22356fe3a120bbe5a5056`.

These values are benchmark metadata, not normative content.
